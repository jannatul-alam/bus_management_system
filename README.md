# Bus Management System

A web-based Bus Management System designed to simplify bus reservation and management processes.

## Features

- User Registration & Login
- Bus Search System
- Seat Booking
- Ticket Generation
- User Profile Management
- Admin Dashboard
- Bus and Booking Management

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## Project Description

This project provides a complete web-based transportation management solution with user and admin functionalities. It helps users search buses, reserve seats, and manage tickets while allowing administrators to control buses and bookings efficiently.

## Purpose

The main objective of this project is to develop an easy-to-use bus reservation and management system for improving transportation services.
